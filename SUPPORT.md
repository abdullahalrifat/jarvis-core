# Support

Use the repository's GitHub Discussions, when enabled, for questions and design
discussion. Use GitHub Issues for reproducible bugs and focused feature
requests.

Before opening an issue:

- read the README and latest changelog;
- confirm the problem occurs on the latest release;
- include Python version, operating system, package version, and a minimal
  reproduction;
- remove API keys, credentials, private prompts, and sensitive trace content.

Security vulnerabilities must be reported privately as described in
SECURITY.md. This community project does not provide a guaranteed response time
or commercial support SLA.
